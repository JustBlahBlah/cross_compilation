## Навігація файлами
### Вихідний код та конфігурація
*   **`main.c`** - Вихідний C-код застосунку. Програма виводить інформацію про систему (Hostname, час, версію ОС, архітектуру) та демонструє роботу з файлами.
*   **`.clang-format`** — Конфігураційний файл, що задає єдиний стандарт форматування C-коду в проєкті.

### Скрипти збірки
*   **`build_host.sh`** - Базовий скрипт для нативної компіляції та аналізу під x86\_64 (HOST).
*   **`build_cross.sh`** - Базовий скрипт для крос-компіляції програми під AArch64 (TARGET).
*   **`build_universal.sh`** - Універсальний "розумний" скрипт. Працює як для нативної, так і для крос-компіляції залежно від наявності змінної середовища `CROSS_COMPILE`.
*   **`build_static.sh`** - Модифікований універсальний скрипт, який збирає програму зі статичною лінковкою.

### Звіти 
Згенеровані звіти, що містять вивід утиліт `readelf`, `ldd`, `size` та `strings` для різних типів збірок.
*   **`General_Report.md`** - **[ГОЛОВНИЙ ДОКУМЕНТ]** Підсумковий файл, який містить порівняльний аналіз усіх виконаних етапів.
*   **`Report.md`** - Звіт результатів базової збірки на HOST-системі.
*   **`Target_Report.md`** - Звіт аналізу крос-скомпільованого бінарника для TARGET за допомогою крос-версій binutils.
*   **`Universal_Report.md`** - Звіт результатів роботи універсального скрипту.
*   **`Static_Report.md`** - Звіт аналізу статично слінкованого файлу, що підтверджує відсутність зовнішніх залежностей.

## Використання

Для універсального використання (нативна збірка):
```bash
./build_universal.sh
```

Для використання універсального скрипту на **ПК (HOST)** для крос-компіляції під Raspberry Pi:
```bash
CROSS_COMPILE=aarch64-linux-gnu- ./build_universal.sh
```
